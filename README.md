# 🚗 AI-Powered Alcohol Detection & Safe Driving System

An intelligent driver-safety system that detects alcohol consumption and abnormal driving behavior in real time. The system combines **alcohol sensing, computer vision, and vehicle-control logic** to identify potentially unsafe driving conditions and respond by reducing vehicle speed, triggering alerts, and simulating controlled vehicle intervention.

### 🔍 Key Features

* 🥃 Real-time alcohol detection using an **MQ-3 alcohol sensor**
* 👁️ Computer-vision-based monitoring of driving behavior
* 🚨 Automatic warning and buzzer alerts during unsafe conditions
* 🐢 Intelligent speed reduction when dangerous behavior is detected
* 🛑 Vehicle intervention logic for critical situations
* 🎮 Integration with **Slow Roads** for a realistic software-based driving simulation
* 🔌 Microcontroller-based hardware integration
* 📊 Real-time sensor data processing and decision making

### 🛠️ Technologies Used

**Hardware:** Arduino / ESP32, MQ-3 Alcohol Sensor, Buzzer
**Software:** Python, OpenCV, Serial Communication, Slow Roads
**Concepts:** Embedded Systems, Computer Vision, Sensor Fusion, Real-Time Monitoring, Intelligent Vehicle Safety

### 🎯 Objective

The goal of this project is to develop a practical driver-assistance system that can detect alcohol-related impairment and unsafe driving patterns early, provide immediate warnings, and initiate appropriate vehicle-safety responses.

> **From detecting the risk to preventing the drive — an intelligent approach to safer roads.**

AI-powered driver safety system that combines MQ-3 alcohol detection, OpenCV-based monitoring, and real-time vehicle-control logic. It detects alcohol and abnormal driving behavior, triggers alerts, and simulates speed reduction or vehicle intervention using the Slow Roads driving environment.
